# DEEV — deev.lu

Marketing website for DEEV, an AI-native digital agency in Luxembourg.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
```

## Deploy

```bash
npx vercel --prod --archive=tgz --yes
```
