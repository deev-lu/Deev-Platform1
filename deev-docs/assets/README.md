# Assets — aus dem Paket DEEV-Brand-Template

Diese Dateien sind **nicht im Repository**: es sind Markenassets und
lizenzierte Schriftdateien aus dem Paket `DEEV-Brand-Template.zip`.
Ohne sie laeuft `make-fonts.mjs` bewusst auf einen Fehler.

Hierher gehoeren:

| Datei | Herkunft im Paket |
|---|---|
| `deev-logo-lockup-navy.png` | `01_assets/` |
| `deev-icon-watermark-12pct.png` | `01_assets/` |
| `Inter-Regular.ttf` | `02_fonts/Inter/` |
| `Inter-Bold.ttf` | `02_fonts/Inter/` |
| `Inter-Italic.ttf` | `02_fonts/Inter/` |
| `JetBrainsMono-Regular.ttf` | `02_fonts/JetBrainsMono/` |

Beide Schriften sind frei weiterverteilbar (Inter unter SIL OFL 1.1,
JetBrains Mono unter Apache 2.0); die Lizenzdateien liegen dem Paket bei.

Nicht die woff2-Dateien aus `public/fonts/` nehmen — das sind auf die
Website zugeschnittene Teilmengen, keine vollstaendigen Schriften.

**Typold gehoert nicht hierher.** Die Marken-Displayschrift wird in den
Dokumenten nicht verwendet: sie ist nicht einbettbar und waere beim
Empfaenger unlesbar. Sie lebt nur im Logo, und das Logo ist ein Bild.
